Your publishing studio.

The portfolio's blog and video library are ready. Connect your hosted studio once to turn on authenticated publishing.

Sign in to content studio ↗

One-time connection

  1. Create a free project at Sanity Manage and a public dataset named production. Your project ID is a public identifier, not a secret.
  2. Copy studio/.env.example to studio/.env.local and enter the project ID. In the studio directory, run npm install, then npm run dev.
  3. Sign in as the project's owner. Run npm run deploy to host the studio, then put its HTTPS address and your project ID in publishing-config.js.
  4. Add your deployed portfolio origin to the project's CORS settings without credentials. Redeploy the portfolio files once. Future published posts and video entries load from the content service.

Only signed-in project members with write access can publish. The public portfolio uses read-only access to published content and never contains a write token.

Every time you publish

For a blog post, add the title, topic, introduction, article, and publication date. Choose “Published on portfolio,” then publish the document. For a video, first upload it to your chosen video host, then add its link, thumbnail, project, and duration in the studio.

The free hosting setup uses video links rather than sending large video files through your portfolio deployment. A connected studio project and your own sign-in are required; this page does not pretend to publish without them.
